## Features
- Separate LAN for each building
- WAN links representing the campus backbone
- Static IP addressing
- Intra-LAN communication verification
- Inter-LAN routing between all buildings
- Wireless connectivity using Access Points
- Web Server hosting the university portal
- FTP file transfer service
- DNS name resolution
- End-to-end connectivity testing using ping

## Services Implemented

### Web Server
Hosts the university portal and allows access from all campus buildings.

### DNS Server
Allows users to access network services using domain names instead of IP addresses.

### FTP Server
Provides file transfer services across the campus network.

### Wireless Access Point
Enables wireless connectivity for network users.
